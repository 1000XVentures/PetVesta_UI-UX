# PetVesta UI/UX

Single-page prototype of the PetVesta mobile app experience, built with React + Vite and static data.

## Run locally

```bash
npm install
npm run dev
```

Then open `http://localhost:5173` (or the port shown in the terminal).

## Build

```bash
npm run build
```

The production build is output to the `dist` folder and is ready for static hosting (e.g. Vercel).

## Vercel deployment

- Framework preset: **Vite**
- Build command: **`npm run build`**
- Output directory: **`dist`**
